Installing

Mac
  1. Open Route Studio.dmg and drag Route Studio into Applications.
  2. The first time, right-click the app and choose Open, then click Open again.
  3. If macOS still blocks it, go to System Settings → Privacy & Security and click Open Anyway.
Windows
  1. Run RouteStudio.exe. There's nothing to install.
  2. If you see “Windows protected your PC”, click More info, then Run anyway.
